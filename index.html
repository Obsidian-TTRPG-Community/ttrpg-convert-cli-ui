          Template guide
          
        

        

          
Every content type — a monster, a spell, an item — is turned into a Markdown
          note by a template, using the
          
          templating engine. In the Templates section you choose which template file
          renders each type. The converter ships a full set (the Get templates step on
          Setup) — most people start from those and tweak.


          
The files you'll see in each dropdown

          
    
            
  • <type>2md.txt — the standard layout.
    • 
            
  • images-<type>2md.txt — same, but embeds portrait/art (needs images copied).
    • 
            
  • monster2md-yamlStatblock-body.txt — emits a Fantasy Statblocks YAML block (turn on the Fantasy Statblocks toggle).
    • 
          

          
Tip: the Recommended button fills every type with a good default from what you have installed.


          
Qute syntax you'll actually edit

          
    
            
  • {resource.name} — drop in a field (name, source, text…).
    • 
            
  • {#if resource.prerequisite}…{/if} — only render when the field exists.
    • 
            
  • {#for tag in resource.tags}- {tag}{/for} — loop over a list.
    • 
            
  • {resource.text} — the fully-rendered body text.
    • 
            
  • Everything between the top --- markers becomes the note's YAML frontmatter.
    • 
          


          
A minimal example

          
---
tags:
{#for tag in resource.tags}- {tag}
{/for}---
# {resource.name}
*Source: {resource.source}*

{#if resource.prerequisite}**Prerequisite:** {resource.prerequisite}

{/if}
{resource.text}
